# Gestor de Repertorios Musicales

Una aplicación web completa para la gestión de repertorios musicales con capacidades de creación de partituras y edición de letras.

## 🎵 Características Principales

### 📋 Gestión de Repertorio
- **Agregar/Editar Canciones**: Registra canciones con información detallada
- **Búsqueda y Filtrado**: Encuentra canciones por título, artista o género
- **Información Musical**: Tonalidad, tempo, género y notas adicionales
- **Almacenamiento Local**: Todos los datos se guardan en el navegador

### 🎼 Creación de Partituras
- **Editor Visual**: Pentagrama interactivo con líneas musicales
- **Configuración Musical**: Compás, tonalidad y tempo ajustables
- **Notas Musicales**: Herramientas para agregar diferentes tipos de notas
- **Gestión de Compases**: Sistema de medidas organizadas

### ✍️ Editor de Letras
- **Editor de Texto Avanzado**: Escribir y editar letras de canciones
- **Estructura Musical**: Botones para insertar versos, coros, puentes, etc.
- **Vista Previa**: Visualizar letras formateadas
- **Metadatos**: Título, artista y género para cada letra

## 🚀 Cómo Usar

### Instalación y Ejecución
1. Clona este repositorio
2. Abre `index.html` en tu navegador web
3. ¡Comienza a gestionar tu repertorio musical!

### Navegación
- **Pestaña Repertorio**: Gestiona tu colección de canciones
- **Pestaña Partituras**: Crea y edita partituras musicales
- **Pestaña Letras**: Escribe y organiza letras de canciones

### Funcionalidades Principales

#### Gestión de Repertorio
- Haz clic en "Agregar Canción" para crear una nueva entrada
- Usa la barra de búsqueda para encontrar canciones específicas
- Filtra por género usando el menú desplegable
- Edita canciones existentes con el botón de edición
- Elimina canciones que ya no necesites

#### Creación de Partituras
- Selecciona compás, tonalidad y tempo
- Haz clic en el pentagrama para agregar notas
- Usa los botones de notas (redonda, blanca, negra, corchea)
- Las partituras se guardan automáticamente

#### Editor de Letras
- Completa la información básica (título, artista, género)
- Usa los botones de estructura para organizar tu canción
- Escribe en el área de texto principal
- Guarda y previsualiza tus letras

## 🎯 Atajos de Teclado

- **Ctrl + N**: Crear nuevo elemento (según la pestaña activa)
- **Ctrl + S**: Guardar letra (en el editor de letras)
- **ESC**: Cerrar modales abiertos

## 💾 Almacenamiento de Datos

La aplicación utiliza localStorage del navegador para guardar:
- Repertorio de canciones
- Partituras creadas  
- Letras escritas

Los datos persisten entre sesiones del navegador.

## 🎼 Ejemplo de Uso

1. **Agregar una canción nueva**:
   - Ve a la pestaña "Repertorio"
   - Haz clic en "Agregar Canción"
   - Completa los datos musicales
   - Guarda la canción

2. **Crear una partitura**:
   - Ve a la pestaña "Partituras"
   - Haz clic en "Nueva Partitura"
   - Configura compás y tonalidad
   - Haz clic en el pentagrama para agregar notas

3. **Escribir letras**:
   - Ve a la pestaña "Letras"
   - Completa título y artista
   - Usa los botones de estructura
   - Escribe en el área de texto
   - Guarda y previsualiza
